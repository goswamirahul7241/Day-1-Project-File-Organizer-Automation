# 🗂 File Organizer Automation

A simple Python script that automatically organizes files in a folder based on their file type  
(Images, Videos, Documents, Music, Archives, Others).

> ⚠️ Note: The script **moves** files. Test on a copy of your data first.

---

## 🔧 Features

- Scans a given folder and organizes all files into subfolders
- Automatically creates folders like:
  - `Images/` – jpg, jpeg, png, gif, bmp, svg, webp
  - `Videos/` – mp4, mkv, flv, avi, mov, wmv
  - `Documents/` – pdf, docx, doc, txt, xlsx, xls, pptx, ppt, csv
  - `Music/` – mp3, wav, aac, flac
  - `Compressed/` – zip, rar, 7z, tar, gz
  - `Others/` – anything not matching above types
