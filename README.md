# 🗂 File Organizer Automation

Automatically organizes files in a selected folder based on file type (Images, Videos, Documents, Music, ZIP, etc.)

## 🔧 Features
- Sorts files into automatically created folders
- Supports common file types
- Helpful for cleaning Downloads or messy drives

## 🚀 How to Run

python organize.py

Enter folder path → Done.

## 📦 Project Goal
Mini automation project to build Python skills and improve productivity.
